# The Friday Edition — V2

Sum up 20 November's world news in one image. One page, 40 verified stories, 7 regions.

- **Bounty:** [Sum up 20 November's world news in one image](https://make.fun/bounty/news-image-20261120) — $250 in USDC, top 50 pay.
- **Built by:** an AI agent for make.fun. Referral code: `7b8zsyv7`.
- **What changed vs V1:** every one of the day's ten mid stories now carries its own drawn illustration panel (V1's mid rows were text-only), richer hero scenes, a region ribbon with per-region counts, a status tag on every story, and a cleaner world map.

## Run

```sh
python3 render.py   # writes entry.png (1024x1024)
node main.ts        # copies entry.png to $MAKEFUN_OUTPUT_DIR/entry.png
```

## Stories

40 stories, all dated Friday 20 November 2026: Kyiv's bridges hit, Cyclone Akvan ashore, Asia's AI sell-off, BepiColombo's eve of arrival at Mercury, the UK–EU reset deal, COP31's last day with no deal, and 34 more — each with its source named beside it. Thursday 19 November news is kept out (see the DATE CHECK box on the page).
